# Proto_BlockBreaker2D

## はじめに

- このゲームはUnityを使用した2Dブロック崩しの実装を学ぶために作成されたものです。
- ゲームとして、スタートからゲームクリアまで遊べるように作りました。

## 作品の概要

- ２Ｄブロック崩しです。
  ステージ選択画面からステージを選択して遊びます。全５ステージ。

## 制作のポイント
- ボール移動の処理はRigidbodyのAddForceでは想定していた動きにならず、移動量を直接設定する形で実装しました。
- ブロック生成は、ステージデータ（CSV）を読み込んで自動で生成されるようにしています。共通化することで、ステージの追加なども簡単にできます。
- 今回はセーブデータを保存できるように作成しました。扱うクラスから自作しています。
- プレイ時に緊張感が出るように、ブロック以外に当たった際に少しずつボールが加速するようにしました。
  
## 課題
- Utilityのスクリプトを始めとして、設計が最適化されていません。また、各種スクリプトの記述が最適化されていないと思います。
- 特にセーブデータ周りのスクリプトは、標準的ではない構成になっているため、使いまわしなどが難しい状況です。
- ゲームステータスやボールの状態など拡張できるようスクリプトは書いたものの、実際に使用していないものがあります。
- UI、グラフィックスが簡単なものしか用意できませんでした。
- 一部BGMの音量が小さいなど、ファイルごとの音量に差がある状態で調整できていません。
  
## おわりに
- ファイルサイズの問題でGitHubにあげられなかったフォントデータがあったり、ブランチやイシューが使えていなかったり、まとめてコミットしてしまったり、ツールの使い方についても反省点が多いです。
- 簡単なゲームということもあり、もう少し早く完成するかと考えていたのですが、実際にはスクリプトのバグやアルゴリズムの不備で時間がかかってしまいました。
- UI、グラフィックスやBGM、効果音など、ゲーム上で実際に目にするもの、耳にするものについてクオリティをもっと高めたいです。
- 何より、設計や仕様などを決めない状態で進めていたため、製作が進むにつれて「どう実装したか」「仕様はどうだったか」といった部分で混乱してしまいました。せめて仕様は作っておくべきだったです。
